# python_charts_projects

🚖 Taxi Trips Data Analysis
🔹 Project Type
Python Project – Data Cleaning & Visualization

🔹 Overview
This project analyzes the NYC Taxi Trips dataset using Pandas, Seaborn, and Matplotlib. The goal is to clean missing values, explore numerical and categorical features, and generate meaningful visualizations to understand taxi trip patterns, fares, and payment methods.

🔹 Features
✅ Data Cleaning

Handle missing values in numerical and categorical columns.

Convert pickup times to proper datetime format.

Drop invalid rows for consistency.

✅ Exploratory Data Analysis (EDA)

Identify numerical vs categorical columns.

Check dataset shape, column types, and missing values.

Group and aggregate data for borough-level insights.

✅ Visualizations

📈 Line Plot – Fare trends over time.

📊 Bar Chart – Total fare by pickup borough.

🥧 Pie Chart – Distribution of trips by payment method.

📉 Histogram – Distribution of trip distances.

📦 Boxplots – Distance distribution by borough.

🔍 Scatterplots – Relationship between distance and fare.

🔥 Heatmap – Correlation between distance, fare, tolls, and total.

🎨 Pairplot – Multi-variable relationships with pickup zones.
